本项目简单设计。主要是区域录制，输出截图，输出gif
1.点击popup中开始录制按钮
2.鼠标拖拽选中一个区域，区域高亮，（这个区域可以拖拽，缩放等）


3.popup中可以输入间隔截图时间，gif间隔时间
4.监听快捷键ctrl+alt+g,开始录制截图，按下alt+g，停止录制，打开popup可以点击下载所有截图
